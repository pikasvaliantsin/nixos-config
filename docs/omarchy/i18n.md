# Shell strings and translations

The shell keeps Omarchy's `I18n` singleton and the vendored English/Russian
catalogs. This port does not ship the upstream language picker. The default is
English; translations are used when `~/.config/omarchy/language` contains a
code known to `default/i18n/locales.json`. Tests can point at another file
with `OMARCHY_LANGUAGE_FILE`.

## Files

```text
vendor/omarchy-shell/default/i18n/en/shell.json
vendor/omarchy-shell/default/i18n/ru/shell.json
vendor/omarchy-shell/default/i18n/locales.json
vendor/omarchy-shell/default/i18n/{en,ru}/{menu,cli,keybindings}.json
```

`shell/Commons/I18n.qml` reads the language file, merges the selected catalog
over English, and exposes:

- `I18n.t("key")` / `Commons.I18n.t("key")` — a string; an optional second
  argument is the English fallback for keys not in a catalog;
- `.arg(value)` — fills `%1` holes;
- `I18n.tn("key", count)` — plural form;
- `I18n.formatNumber(value, decimals)`;
- `I18n.rightToLeft`.

Use `I18n` with an unqualified `import qs.Commons`, or `Commons.I18n` when
the file imports `qs.Commons as Commons`. Keep `I18n.t()` inside bindings so a
language change re-renders the UI. The same applies to `tn`, `formatNumber`
and `rightToLeft`.

## Adding a string

1. Add the key to `default/i18n/en/shell.json`.
2. Add the same key to `default/i18n/ru/shell.json` (Russian is the maintained
   second catalog here).
3. Read it with `I18n.t("area.key")`, keeping the whole sentence in one key
   with `%1` placeholders rather than concatenating translated fragments.
4. For a custom panel that is not translated yet, either add both catalogs or
   use `I18n.t("key", "English fallback")`. Do not leave a translated-looking
   key with no English fallback.

Keep command output, usage text and diagnostics in English. Product names,
commands, paths, key names and placeholders are not translated.

## Current custom strings

The clipboard center uses `clipboard.search`, `clipboard.empty`,
`clipboard.deleteHistory`, `clipboard.deleteUnpinned`, `common.delete`,
the `clipboard.files`/`clipboard.image*` plural keys and
`common.noMatchesFor`. The notification center, OpenCode panel, capture menu,
reminder menu and sudo menu currently contain English literals; add catalog
keys before claiming they are localized.

## Date, time and numbers

- Displayed numbers use `I18n.formatNumber()`, not `toFixed`/`toLocaleString`.
  The OpenCode panel additionally compacts token counts to `K`/`M`/`B`.
- Date labels currently use Qt's default locale through `Qt.formatDateTime`.
  If month or weekday names should follow the shell language, pass
  `Qt.locale(I18n.formatLocale)` explicitly.
- The OpenCode reset labels use `Qt.formatDateTime` for the absolute time and
  compute the relative remainder from `Date.now()`.
- The clock format is the `format` value under `bar.layout.center` in
  `home-manager/modules/desktop/omarchy/shell.json`; change it there, not in
  QML.

## Validation

There is no upstream translation test suite in the vendor. At minimum:

```bash
find vendor/omarchy-shell/default/i18n -name '*.json' -exec jq empty {} +
```

Then verify the rendered string in a running shell by opening the relevant
panel or menu through `omarchy-ipc`.
